# CSV Sales Analysis

A Python project for analyzing sales data from a CSV file and creating a simple revenue chart.

## Features

- Read sales records from a CSV file
- Calculate total revenue
- Find the best-selling product
- Summarize revenue by product
- Summarize revenue by month
- Export a text report
- Create a revenue chart using Matplotlib

## Technologies Used

- Python
- CSV File Handling
- Matplotlib
- Data Analysis

## How to Run

Install Matplotlib if needed:

```bash
pip install matplotlib
```

Run the project:

```bash
python sales_analysis.py
```

## Project Structure

```text
csv-sales-analysis-python/
├── sales_analysis.py
├── sales_data.csv
├── sales_report.txt
├── revenue_by_product.png
└── README.md
```

Note: `sales_report.txt` and `revenue_by_product.png` are created after running the program.

## Project Purpose

This project was created to practice Python data processing, CSV handling, basic analysis, and data visualization.
